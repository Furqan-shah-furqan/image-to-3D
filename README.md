# Forma — Image to 3D Studio

A Vercel-ready image-to-3D workspace built for Furqan Shah. Upload an image, connect your own Gemini API key, generate an approximate procedural 3D reconstruction, refine it against a rendered preview, and export a GLB, editable JSON, or self-contained Three.js module.

The full [img2threejs](https://github.com/img2threejs/img2threejs) toolkit is imported alongside this web app. The original README is preserved in [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md). Imported source commit: `6e60b5e22419464b4853e01ddb6c0e6f6659a733`.

## Use the studio

1. Click **Add API key** at the top right. Get a key at <https://aistudio.google.com/apikey>.
2. Click **Connect & validate key**. Compatible models are loaded from Google's API; choose one or keep Auto (which prefers a stable full Gemini Flash model).
3. Close the dialog and upload a JPG, PNG, or WebP, up to 20 MB. Images are decoded and compressed in the browser to at most 1280 pixels before being sent.
4. Add optional instructions and select Draft, Balanced, or Detailed. Click **Generate 3D model**.
5. When Compare & refine is enabled, the browser sends a real render and the original reference to Gemini for a visual review. If needed, it makes one correction pass and reviews the final render again. This can use four Gemini requests in total. Any review failure is shown without discarding the generated model.
6. Orbit, zoom, change material colours/roughness/metalness, adjust lighting/background, show wireframe, and compare with your source image.
7. Use **Refine model** for additional changes. Export GLB for 3D/AR tools, JSON for the scene data, or Three.js for procedural source. The downloaded module imports `three` and its official RoundedBoxGeometry addon.

## Local setup

Requires Node.js 22 or newer.

```sh
npm ci
npm run dev
```

Open <http://127.0.0.1:5173>. The local server runs both Vite and the same API handlers used on Vercel. No server API key or database configuration is needed; users supply their own keys through the UI.

```sh
npm test
npm run build
```

## Vercel deployment

Import `Furqan-shah-furqan/image-to-3D` into Vercel. Use the repository root, Vite framework, `npm run build`, and `dist` output. `vercel.json` configures these settings and Node API function durations. Enable Fluid Compute for the generation handler's 300-second execution allowance. Future pushes to `main` deploy through the Git integration.

## What the web adapter implements

The web app uses the upstream image-analysis protocol and procedural geometry guide in its Gemini system prompt. It translates image observations directly into **WebSceneSpec**, a bounded declarative scene format supported by our browser renderer: boxes, bevelled boxes, spheres/ellipsoids, capsules, cylinders, cones, tori, lathes, curved tubes, extruded outlines and indexed meshes. Materials use physically based Three.js shading.

`lib/scene-spec.js` checks geometry budgets, finite transforms, material references, hierarchy cycles and triangle buffers. It never executes generated JavaScript. The viewer constructs Three.js objects deterministically from validated data; the source-code download is generated by our renderer, not arbitrary model-authored code.

**This adapter is not the entire upstream strict ObjectSculptSpec/Python pass-gating pipeline.** The upstream `forge/`, `grimoire/`, `SKILL.md`, documentation and integration scripts remain available for the full agent workflow. The browser format is intentionally separate and does not bypass or claim to pass the upstream strict quality gates. AI review scores are subjective similarity estimates, not certified geometric accuracy. A single image cannot determine hidden surfaces; human faces, textures and complex organic subjects are approximate. No automatic rigging or animation generation is claimed.

## Privacy, quota and cancellation

- Your API key is stored only in `sessionStorage` for the current browser tab; removing it clears the stored key. It is never committed, logged, or saved in a server database.
- Requests travel through this app's same-origin HTTPS API functions to Google's Generative Language API. The functions need your key transiently to authenticate. Reference images and generated scenes are sent to Google; Google's data-handling and billing terms apply.
- API routes use POST and `Cache-Control: no-store`. They validate input size and image signatures. Invalid keys, unavailable models, exhausted quota, blocked images, truncated output and timeouts produce explicit errors.
- Generation requires a Gemini key with compatible models and sufficient quota. There are no fake success results or placeholder fallbacks. Example gallery items are explicitly labelled handmade examples.
- Cancel aborts browser requests and restores the previous model. A Google request already running may still finish and incur usage.
- Models remain in the current workspace session. Download exports before reloading to keep your work.

## Project layout

| Path | Purpose |
| --- | --- |
| `index.html`, `src/` | Responsive studio, Three.js viewer and exports |
| `api/generate.js` | Reference image + Gemini structured scene generation/refinement |
| `api/review.js` | Reference/render visual comparison |
| `api/models.js` | Key validation and available-model discovery |
| `lib/` | Schema validation, Gemini REST client, upstream-derived prompt |
| `tests/web.test.js` | Renderer/schema and API contract checks; mocked provider, no real usage |
| `forge/`, `grimoire/`, `integrations/` | Complete imported upstream toolkit |

The visual theme is inspired by the two supplied studio references: warm off-white surfaces, compact side panels, rounded controls, muted olive accents and a blue action button. No reference images are used as fake 3D output.
